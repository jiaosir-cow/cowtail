# Six user-attested field identities: initial resource-limited experiment

Frozen before any new model outcomes. This is a retrospective experiment using the user's 2026-10-18 field-record identity correction. The six IDs are user-attested, not independently verified. Preserve legacy identities and session-group provenance in every dataset release; do not relabel old experiments or their conclusions.

Dataset: `datasets/six_cows_field_record_20261018`, 781 eligible original four-state intervals, 28,911 existing nonoverlapping 256-frame windows. Only normalized three-axis acceleration enters the model. The other legacy cattle are excluded from this initial six-ID experiment. No new human annotations or new sensor recordings were collected by this pipeline.

Alias order and IDs: cowA=COWID_04; COW_OTHER=COWID_05; COW_OTHER=COWID_01; cowC=COWID_06; cowD=COWID_07; COW_OTHER=COWID_08. Each of six folds holds out one user-attested ID, trains on the other five and masks all held-out targets to -1. No separate validation labels or target-selected checkpoint. Train/test intervals, windows and sessions must be disjoint. Legacy recording IDs are retained for the audit; evaluation by revised IDs remains conditional on the user's identity attestation and is not independently confirmed six-animal generalization.

Initial grid: six folds x two original-interval budgets (10%, 100%) x three methods (scratch, ActBeCalf, UFRO) x one computational repetition (seed index 0) = 36 training runs. All methods use identical selected intervals and identical 3,000 batches of 32. Reuse the historical class-blind interval ordering and interval-first uniform sampler, base seed 20260909. No class balancing, missing-class redraw or outcome-based subset selection. Class supports are descriptive only. E has no feeding truth; F has no lying truth. Keep all four prediction outputs and report fixed-four-class metrics, alongside class support and per-cow results. Do not create absent class labels or treat repeats/windows as animals.

Reuse the frozen 828-parameter hierarchy and safe pretrained source states. Adam lr=0.001, fixed FP32, no AMP/TF32/compile, all target parameters train. Fixed 1,000 updates is primary; fixed 3,000 is a sensitivity checkpoint from the same run. Retain all results and failures. No checkpoint, seed, class or cow selection based on test performance. Predictions are saved without target scoring on the server; full truth stays local for subsequent scoring after prediction receipts are verified.
